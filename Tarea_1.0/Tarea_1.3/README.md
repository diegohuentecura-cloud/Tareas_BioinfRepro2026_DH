### Repository Objective

This folder contains the scripts created to divide the original bioinformatics pipeline into independent subscripts, with each file representing a specific step of the analysis.

The activity also includes a **master script**, called **`pipeline.sh`**, which executes all the subscripts sequentially and in the correct order.
