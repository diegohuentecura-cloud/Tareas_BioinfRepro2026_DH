### Repository Objective
This folder contains the activity `Tutorial para el filtro y alineamiento de lecturas`
The objective of this activities is to document the filtering, alignment, and quality assessment of sequencing reads from sample S3 against the human reference genome hg19.

### Conclusion
This activity helped me learn how to filter sequencing reads, align them against a reference genome, and evaluate alignment quality using bioinformatics tools. I also learned to identify potential problems related to coverage, read duplication, and mapping quality.

These skills can be applied to genomic research, for example, to analyze patient sequencing data and identify genetic variants. They are relevant because they help ensure the quality, reliability, and reproducibility of bioinformatics analyses
