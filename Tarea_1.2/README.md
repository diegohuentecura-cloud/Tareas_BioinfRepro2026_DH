### Repository Objective

This folder contains the files for **Activity 2**, which focuses on the analysis and interpretation of a bioinformatics pipeline written in Bash.

The activity is based on a script that processes genomic samples using different bioinformatics tools, including **`gsnap`**, **`samtools`**, **`pstacks`**, **`cstacks`** and **`sstacks`**.

The document includes answers to the following questions:

* Identification of the main steps included in the script.
* Explanation of the path that should be modified to run the script on a personal computer.
* Description of the meaning of **`$HOME`**.
* Explanation of the role of **`gsnap`** in the analysis.
* General description of the function performed by each **`for` loop** included in the pipeline.

The activity also describes how the script aligns genomic samples, converts SAM files to BAM format, processes samples with **Stacks**, builds a catalog, matches samples against the catalog, and calculates population statistics.

The activity was completed and documented using **Markdown** format.
